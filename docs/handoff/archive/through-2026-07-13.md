## 长期有效的历史决策

1. `severity` 只采用 `PASS`、`WARN`、`FAIL`、`NEED_REVIEW`。
2. registry 是系统认可的可执行规则真源；规划、参考或文档中的检查点不能自动进入“已执行”。
3. `execution_ledger` 记录本次运行事实，observation 解释 HOW 和取数证据，UI/JSON 不新增判断。
4. SAD、TT、TE 含义不同，不能在 UI 或 LLM 提示中作为同一阈值混用。
5. K.02 新增应区分购置与非购置变动；具体 finding 应尽量锚定实际业务工作表和单元格。
6. K.03 折旧测试通常在 SAP 中精度、SAP 高精度、TOD by-item、TOD 抽样中选择实际路径；K.03.3 政策复核独立处理。
7. 报告和标注是双必交付；标注写入原底稿副本，不覆盖用户原件。
